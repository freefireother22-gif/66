# Parental Control

A modern, production-grade Android Parental Control application built with Kotlin and Jetpack Compose.

## Key Features

- **Role Selection**: Seamlessly choose between Parent/Guardian and Child modes.
- **Secure OTP Pairing**: Single-use 6-digit cryptographic pairing protocol connecting parent and child devices.
- **Real-Time Monitoring**: WebRTC live screen viewing and audio monitoring with WebRTC peer-to-peer streaming.
- **Location Tracking**: Real-time GPS location tracking with breadcrumb history and safety boundary status.
- **Safeguard Permissions**: Step-by-step setup for Device Admin protection, Accessibility safeguards, Battery optimization exemption, and Notification sync.
- **Parent Dashboard**: Comprehensive dashboard showing device status, battery level, online indicators, and quick-action emergency safeguards.

## Run Locally

**Prerequisites:** [Android Studio](https://developer.android.com/studio)

1. Open Android Studio.
2. Select **Open** and choose this project directory.
3. Allow Gradle to sync and build dependencies.
4. Run the app on an Android emulator (API 24+) or physical device.
